# 檢索結果適用性評估基準

依據環境部氣候變遷署《碳足跡數據品質評估手冊》第三版（114年10月）表2，以可靠性、完整性、時間相關性、地理相關性、技術相關性，輔助判斷檢索結果是否適合採用。

評估直接呈現在單筆檢索的「完整資訊／適用性與資料品質」，並納入單筆與批次下載。無獨立DQR頁面，也不要求填寫十項評分才能檢索。

## 證據

- 來源已提供 `dqr_factor_Re/Co/Ti/Ge/Te` 及各自 `_evidence` 時，接受1–5整數評級及佐證。
- 時間相關性由數據年度與研究年度計算；未指定研究年度時明示暫採本年度。3、6、10、15年邊界因手冊文字及示例存在差異而標示待確認。
- 可靠性須有量測、假設、估算方式及查證證據；官方或Tier 1不自動等於高品質。
- 完整性須有場址、資料期間與代表性證據，不以欄位填寫比例替代。
- 地理與技術相關性須有研究情境及生產條件證據，不以同國別、產品名稱或行業路由推定最佳評級。
- 無足夠證據時標示待確認。

## 適用性

五項評估與品名、單位、生命週期邊界、氣體種類等檢查共同影響適用性分數及採用建議。手冊等級越低越好。系統內部排序用 `(6-等級)/5` 正規化，未知項採保守值0.4。權重和門檻是系統政策，不是手冊公式。

五項證據缺漏時綜合分數上限0.64，不能直接宣告建議採用；任一項第4–5級時綜合分數上限0.49，列為不建議直接採用並指出限制。

此處不計算產品整體DQR或宣告產品高／基本／初估品質。完整DQR計算函式僅保留作為內部公式驗證，未接入檢索介面。
