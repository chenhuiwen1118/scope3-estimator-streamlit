## 🚧 風險與應對

### 風險 1：微調效果不佳
- **風險等級**：中
- **影響**：檢索準確度提升不到 10%
- **應對**：
  1. 增加訓練資料量（5000 → 10000）
  2. 嘗試不同的 Loss Function
  3. 使用更大的模型（MiniLM → BERT-base）

### 風險 2：LLM 幻覺率高
- **風險等級**：高
- **影響**：生成的解釋不準確
- **應對**：
  1. 加強提示約束（只使用提供的資訊）
  2. 實作嚴格的幻覺檢測
  3. 降級為模板式輸出（犧牲靈活性但保證準確性）

### 風險 3：系統效能不足
- **風險等級**：低
- **影響**：延遲 > 3 秒
- **應對**：
  1. 模型量化（8-bit → 4-bit）
  2. 更換更快的 LLM（Qwen → Llama）
  3. 分離檢索與生成（先返回檢索結果）

### 風險 4：GHG 分類準確度不足
- **風險等級**：中
- **影響**：分類 F1 < 85%
- **應對**：
  1. 增加人工標註資料
  2. 使用更大的模型（BERT-base → BERT-large）
  3. 加入規則輔助（關鍵字 + 模型預測）
