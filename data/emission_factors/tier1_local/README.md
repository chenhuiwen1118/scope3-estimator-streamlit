**優先順序**: 第一優先使用
**區域**: 台灣

---

## 🎯 使用原則

根據 GHG Protocol 與 ISO 14064-1，排放係數選用應遵循以下順序：
1. **Tier 1 (本土係數)** ← 優先使用
2. Tier 2 (國際產業特定係數)
3. Tier 3 (EEIO 通用係數)

**本層級 (Tier 1) 的係數最精確，最能反映台灣本地的排放特性。**

## 🔍 檢索策略

### RAG 向量檢索設定
```python
# Tier 1 檢索參數建議
tier1_config = {
    "top_k": 5,
    "similarity_threshold": 0.75,  # 較高門檻，確保精確匹配
    "weight": 1.0,  # 最高權重
    "language": "zh-TW"  # 繁體中文優先
}
```

### 檢索邏輯
1. **使用者輸入**: 採購活動描述（中文或英文）
2. **向量化**: 使用多語言 embedding 模型
3. **檢索 Tier 1**: 搜尋本層資料庫
4. **信心度判斷**:
   - 若相似度 ≥ 0.75 → 使用 Tier 1 係數 ✅
   - 若相似度 < 0.75 → 轉至 Tier 2 ⏩
